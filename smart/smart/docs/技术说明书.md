# 智能头盔管理系统 — 技术说明书

## 1. 系统概述

| 项目 | 说明 |
|------|------|
| **名称** | Smart Helmet Management System（智能头盔管理系统） |
| **类型** | B/S 架构 Web 应用（SPA 前端 + REST API 后端） |

## 5. 认证流程

```
用户 → 登录页 → POST /login (Basic Auth)
  → 后端代理至上游 API
  → 上游不可用时：本地生成临时 token (local_xxx)
  → 返回 JWT token → 存 localStorage
  → 后续请求携带 Authorization: Bearer <token>
  → 401 时前端自动跳转 /login
```

- 登录：Basic Auth → 上游 Basic 认证 → 返回 Bearer token
- 鉴权：所有业务 API 携带 Bearer token → 上游验证
- 降级：上游不可用时生成 `local_` 前缀临时 token

## 6. 本地数据库

- **引擎**: SQLite 3（文件型，零配置）
- **文件**: `smart_helmet.db`
- **创建策略**: 启动时 `Base.metadata.create_all()` 自动建表
- **启动清理**: 每次启动清空 `users` / `roles` 表，重置 `company.admin_username`

## 8. 部署方式

### 8.1 开发环境（一键启动）

```bat
start.bat
```
自动完成：pip install → npm install → 启动后端(:9000) → 启动前端(:5200)

### 8.2 生产环境（Docker Compose）

```bash
docker compose up -d --build
```

- **frontend** (nginx:alpine, :5200)：SPA 静态服务 + `/api/` `/ws/` 反向代理至后端
- **backend** (python:3.13-slim, :9000)：FastAPI + SQLite
- **数据持久化**：Docker 命名卷 `smart_helmet_db` + `smart_helmet_storage`

### 8.3 环境变量

| 变量 | 必填 | 默认值 | 说明 |
|------|------|--------|------|
| `UPSTREAM_BASE_URL` | 否 | `https://api.znhaas.net:2443` | 上游 API 地址 |
| `TALK_WS_BASE_URL` | 否 | `wss://api.znhaas.net:2443` | 对讲 WS 地址 |

## 9. 关键设计决策

| 决策 | 原因 |
|------|------|
| 后端作为上游代理而非直连 | 统一鉴权、CORS 处理、本地缓存降级、WS 中继 |
| SQLite 而非 PostgreSQL | 零配置、单实例部署够用、文件型方便备份 |
| 上游 SSL 证书校验关闭 | 上游自签证书，开发环境简化（生产应开启） |
| CORS 允许全部来源 | 内网部署，不暴露公网 |
| 启动时清空本地用户表 | 确保认证数据以上游为准，本地仅做缓存 |
| 双 key 命名兼容（camelCase + snake_case） | 兼容不同版本上游 API 返回格式 |
